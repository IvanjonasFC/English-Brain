# Robust Content Pipeline: Ingestion, Provenance, CEFR Validation & Versioned Snapshots

This document outlines the architecture and execution plan for the **Robust Content Pipeline** for English Brain. It enables controlled importation of external and local LLM-generated material, strict CEFR classification, license enforcement, and offline-first delta synchronization between the NAS/backend and the mobile app.

---

## User Review Required

> [!IMPORTANT]
> **Key Architecture Decisions:**
> 1. **State Machine (`source` → `raw` → `normalized` → `reviewed` → `published`)**: No content ever enters the published snapshot without human review (`reviewedBy`, timestamp, verified CEFR level).
> 2. **License Enforcement**: Content with `license != 'own'` (e.g. materials from BBC, British Council, Cambridge) is strictly restricted to external reference URLs/metadata; embedding copied text under proprietary licenses is rejected by the pipeline validator.
> 3. **Versioned Snapshots & Deltas**: Every publication increments the snapshot version (`v1.0.0`, `v1.1.0`...) and generates a `manifest.json` with SHA-256 checksums. The mobile app queries `GET /api/content/delta?since=vN` and applies incremental updates directly into Drift SQLite without requiring full redownloads.
> 4. **Review Interfaces**: Both a REST API (`/api/content/...`) and an interactive Python CLI tool (`tools/content_cli.py`) will be provided so you can approve batches in seconds.

### Backend API Endpoints

#### [NEW] [`backend/app/routers/content.py`](file:///c:/Users/IvN/Desktop/Ingles/backend/app/routers/content.py)
- `POST /api/content/ingest/batch`: Ingests JSON/CSV batches from user or local LLM (Ollama) into `normalized` state.
- `GET /api/content/pending`: Lists items pending review, filterable by `content_type` and `scenario`.
- `POST /api/content/items/{id}/review`: Approves (with CEFR validation), modifies, or rejects items with notes.
- `POST /api/content/publish`: Bundles all reviewed items into a new versioned snapshot (`vN`), updates manifest.
- `GET /api/content/latest`: Returns current manifest and active snapshot.
- `GET /api/content/delta`: Incremental delta query (`?since=v1.0.0`).
- `GET /api/content/audit`: Returns consistency check report.

  - `python tools/content_cli.py publish --bump minor`: Publishes new snapshot.
  - `python tools/content_cli.py audit`: Runs consistency and licensing audit.
